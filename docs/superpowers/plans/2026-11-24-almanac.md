# 리그 연감: 전광판 교체 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사이트 전체(운영, 로딩, 배틀, 도전의 탑 포함)의 전광판 요소를 리그 연감 스타일로 하나도 빠짐없이 바꾼다.

**Architecture:** 공용 층에서 먼저 바꾼다. 면 토큰(`--panel`, `--panel-2`)을 바탕과 같게 두어 모든 패널 배경을 한 번에 지우고, 패널 자리에는 머리카락 줄을, 반전 자리에는 2px 줄을 둔다. 세그먼트 컴포넌트는 같은 API의 가는 숫자 컴포넌트(`Fig`)로 바꾼다. 그 뒤 화면마다 캡처를 보며 남은 흔적을 고친다.

**Tech Stack:** React 18, plain CSS (`src/styles/`), Albert Sans 가변 굵기, Freesentation.

**Spec:** `.design-board/2026-11-24-almanac/` 기록 초안 (`?p=records`)과 2026-11-24 대화의 설계 (아래 Global Constraints).

## Global Constraints

- 남색 `#081C3D`, 두 테마, 고대비, Freesentation과 Albert Sans, 황금비 간격은 그대로.
- 패널 배경 없음. 섹션은 2px `--lit` 줄로 열리고, 항목 사이는 1px `--rule` 줄.
- 반전 없음. 결정되었거나 고른 것은 `--lit` 글자와 그 아래 2px `--lit` 줄. 채운 면은 주 행동 키와 토스트만.
- 숫자 표시는 7세그먼트 대신 Albert Sans 가는 숫자 (84 이상 200, 40 이상 300, 그 아래 400). 앞자리 0은 시계만 남긴다.
- 램프: 호박색 사각은 "지금 진행 중"에만. 꺼진 램프 자리는 없앤다. 도전의 탑의 램프는 하트 아이콘, 글은 "하트".
- 바쁨: 세그먼트 칸 대신 가는 줄 하나가 지나간다. 로딩은 줄만 그어진 빈 자리.
- 시트, 대화창, 메뉴는 바탕색 면에 테두리 줄로 구분한다.
- 홈은 배치를 그대로 두고 부품만 바뀐다.
- 기능과 데이터 동작은 바꾸지 않는다.

## Review Focus

- 반전 자리 안의 글자가 바탕색으로 남아 안 보이는 곳 (`color: var(--ground)`): 모든 화면 캡처로 확인.
- 면이 사라져 경계가 없어진 입력칸, 체크박스, 스위치: 폼과 시트에서 확인.
- 배틀 HUD가 경기장 그림 위에서 읽히는지: 두 테마로 한 판.
- 숫자 크기가 바뀌어 줄이 넘치거나 겹치는 곳: 390에서 확인.
- 밝은 테마와 고대비에서 줄이 보이는지.
