# League almanac scoreboard replacement plan

> For agentic workers: use the required sub-skill `superpowers:executing-plans` to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

Goal: replace every scoreboard element across the entire site (including admin, loading, battle, and 도전의 탑) with the league almanac style, leaving none behind.

Architecture: update the shared layer first. Set surface tokens (`--panel`, `--panel-2`) equal to the ground color to clear all panel backgrounds in one pass, placing hairline rules where panels sat and 2px rules where inversions sat. Replace the segment component with a thin-figure component (`Fig`) sharing the same API. Then capture every screen and clean up any remaining artifacts.

Tech stack: React 18, plain CSS (`src/styles/`), Albert Sans variable weight, and Freesentation.

Spec: the `기록` draft (`?p=records`) in `.design-board/2026-11-24-almanac/` and the 2026-11-24 design decisions in the constraints below.

## Global constraints

- Keep navy `#081C3D`, both themes, high contrast, Freesentation and Albert Sans, and golden-ratio spacing.
- No panel backgrounds. Open sections with a 2px `--lit` rule and separate items with a 1px `--rule` hairline.
- No inverted fills. Mark active or selected states with `--lit` text and a 2px `--lit` rule underneath. Restrict filled surfaces to primary action buttons and toasts.
- Replace 7-segment digits with thin Albert Sans figures (weight 200 at 84px and up, 300 at 40px and up, 400 below 40px). Keep leading zeros only on clocks.
- Use the amber square lamp strictly for live in-progress states, and remove unlit lamp slots. In 도전의 탑, replace lamps with heart icons and label them `하트`.
- Replace busy segment cells with a single thin moving line. Show loading states as empty slots outlined only by rules.
- Separate sheets, dialogs, and menus with ground-colored surfaces and border rules.
- Keep the home page layout unchanged, updating only its components.
- Do not change functionality or data behavior.

## Review focus

- Check every screen capture for text left in the ground color (`color: var(--ground)`) inside former inverted slots, making it invisible.
- Inspect forms and sheets for inputs, checkboxes, and switches that lost their boundaries when panel fills disappeared.
- Play one match in both themes to confirm the battle HUD reads clearly over the arena graphic.
- Check 390px screens for wrapping or overlap caused by the new figure sizes.
- Confirm rules stay visible in both light theme and high contrast.
