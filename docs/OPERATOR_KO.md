# 운영진 빠른 안내 (한국어)

비개발자 동아리 임원이 코드 수정 없이 대회를 열고 사이트를 유지하기 위한 핵심 요약입니다. 전체 영문 원문은 [OPERATOR.md](OPERATOR.md), 계정과 시크릿 인계는 [HANDOVER.md](HANDOVER.md), 장애 대응은 [RUNBOOK.md](RUNBOOK.md)를 참고합니다.

## 1. 관리자 로그인과 운영 화면

1. 모바일은 `더보기` 화면 하단, 데스크톱은 바닥글 오른쪽 끝에서 `관리자 로그인`을 누릅니다.
2. 운영진 계정으로 로그인한 뒤 하단 관리자 띠의 `운영` 버튼(`?view=admin`)을 엽니다.
3. 로그인은 브라우저 탭을 닫을 때까지 유지됩니다.

## 2. 대회 한 회차 운영 순서

1. 공지와 신청서: `운영`의 편집에서 `공지 쓰기`를 누르고 대회 정보와 신청서를 채워 저장합니다. 이전 대회와 설정이 같으면 `지난 대회에서 불러오기`를 씁니다. 미리 써 두고 싶으면 `게시 예약` 시각을 지정합니다.
2. 신청 확인과 마감: `운영`에서 신청자 수를 확인하고, 일찍 닫아야 하면 `지금 마감`을 누릅니다. 참가자가 구글 계정 연결을 요청하면 상단 `연결 요청`에서 승인하거나 거절합니다.
3. 파티 제출 확인: 참가자가 제출 비밀번호를 잊으면 대진표의 제출 현황에서 `비밀번호 초기화`를 눌러 줍니다.
4. 대진표 생성: `대진표 만들기`에서 방식을 고르고 참가자를 체크합니다. 당일 체크인을 받았다면 `체크인한 N명`으로 한 번에 고릅니다. `다시 추첨`이나 두 자리 연속 클릭으로 대진을 조정한 뒤 확정합니다.
5. 경기 진행: 경기 칸을 눌러 승자와 점수, `불참`, `기권 처리`, `실격 처리`, `선출`을 입력합니다. 사이트 배틀이 멈추면 `시계 멈춤`이나 `배틀 무효`를 씁니다.
6. 기록과 칭호 반영: 모든 경기가 끝나면 `기록에 반영`에서 순위와 포인트를 확인하고 `이대로 반영`을 누릅니다. 이어서 뜨는 칭호 후보를 확인해 `칭호에 반영`합니다. 실수가 있으면 대진표에서 `반영 취소`로 한 번에 되돌린 뒤 다시 반영합니다.

## 3. 코드 수정 없이 바꿀 수 있는 사이트 설정

`운영` 화면의 편집 목록에서 `포인트`와 `사이트 설정`을 열면 아래 항목을 바로 바꿀 수 있습니다.

- 순위별 랭킹 포인트 정책 (`포인트`)
- 디스코드 초대 주소 (`사이트 설정`)
- 소개 화면의 리그 연혁 추가 및 수정 (`사이트 설정`)
- 개인정보처리방침 시행일과 창립 연도 (`사이트 설정`)

## 4. 문제가 생겼을 때

- 방문자 화면에서 발생한 오류는 `운영` 하단 `화면 오류`에서 줄을 눌러 상세 내용을 확인합니다.
- 자동화 작업(생존 확인, 주간 백업, 푸시 알림, 배포)이 실패하면 GitHub 이슈 `"자동 작업 실패: ..."`가 열리며, `DISCORD_ALERT_WEBHOOK`을 설정해 두면 운영진 디스코드로도 바로 알림이 옵니다.
- 복구, 백업 복호화, 레귤레이션 전환 같은 개발 작업은 [RUNBOOK.md](RUNBOOK.md)를 따릅니다.
